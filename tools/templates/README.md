# Templates made by dein.art

These scripts make the free template packs in `prototype/files/templates`, all released under CC0:

```bash
python3 luts.py        # eight film looks as .cube LUTs, with before/after previews (needs numpy and Pillow)
python3 overlays.py    # film grain, dust and scratches, and light leaks as 1080p clips (needs numpy and ffmpeg)
node titles.mjs        # lower thirds and silent-film intertitles as SVG and transparent PNG (needs Chrome)
```
